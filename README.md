**Тема проекта**

Разработка агента для адаптации модели системы сбора продукции скважин в PIPESIM.

**Задача агента**

Агент запускает расчёты PIPESIM, сравнивает расчётные давления и расходы с промысловыми данными, находит участки с наибольшей невязкой и помогает адаптировать модель сети.

## Структура

- `agent.py` — `run(request, ctx) -> AgentResult`
- `project.yaml` — название, пара, точка входа
- `requirements.txt` — зависимости
- `.env.example` — имена переменных без значений
- `src/agent/` — `schemas.py`, `tools.py`, `loop.py`, `prompts.py`
- `tests/` — pytest
- `notebooks/demo.ipynb` — демо для Colab
- `docs/` — схема агента, слайды защиты
