# Данные таблицы АГЗУ

Источник: `Дебиты и давления по АГЗУ.xlsx`, лист `Sheet1`.
Проверка выполняется скриптом `scripts/check_agzu.py`.

## Поля

| Поле в коде | Колонка | Значение | Правило |
|---|---|---|---|
| well_id | A | Обозначение скважины | Хранится строкой |
| liquid_rate | B | Дебит жидкости: нефть и вода вместе | Неотрицательное число |
| water_cut | C | Обводнённость | Доля от 0 до 1; например, 0,13 означает 13% |
| gas_rate | D | Дебит газа | Неотрицательное число |
| water_rate | Вычисляется | Дебит воды | liquid_rate × water_cut |
| group | По расположению блока | Принадлежность к АГЗУ | Задана для строк исходной таблицы |

Единицы дебитов и условия учёта газа требуют подтверждения.
До этого суммы используются только для проверки импорта.
Самостоятельной колонки измеренных давлений в A:F нет.

## Пропуски и проверки

- Пустая ячейка сохраняется как `null`, а не заменяется нулём.
- У скважин 114 и 116 отсутствуют liquid_rate, water_cut и gas_rate.
- Значение 0 в исходной ячейке отличается от пропуска.
- Дебит воды пересчитывается по B и C. Ноль в формуле F при пустых входах не считается известным дебитом.
- Отрицательные значения, ошибки Excel, бесконечность и обводнённость вне диапазона отклоняются.
- Скрипт проверяет обозначения скважин в ожидаемых строках. При изменении структуры таблицы проверка останавливается.

## Итоги

В суммы входят только строки скважин с заполненными B, C и D.
Строки итогов и блок «АГЗУ-7 + АГЗУ-60» повторно не учитываются.

Общая обводнённость = сумма дебитов воды / сумма дебитов жидкости.
При нулевой сумме жидкости она не определена.

Исходная формула C36 пропускает F32. Исправленный итог сохраняется
в отдельном отчёте; исходный Excel не изменяется.

Суммы по заполненным строкам не считаются полным расходом сети
при наличии скважин с неизвестными параметрами.

## Отчёт

Результат сохраняется в `agzu_audit.json` рядом с папкой `raw`.

Отчёт содержит имя и SHA-256 исходника, адреса ячеек, значения,
пропуски, итоги и сведения о формуле C36.

- COMPLETE — заполнены три входных параметра строки.
- INCOMPLETE — отсутствует хотя бы один параметр.

COMPLETE означает полноту строки, но не готовность к расчёту PIPESIM.
Единицы, свойства флюида и граничные условия подтверждаются отдельно.

Десятичные числа в JSON записаны строками для сохранения точности.
Пропуски записаны как `null`.

Исходники и отчёты хранятся локально, вне публичного репозитория.
